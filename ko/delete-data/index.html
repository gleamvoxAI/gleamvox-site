내 데이터 삭제

Gleamvox에는 서버도 계정도 없으며 휴대폰 밖에 사용자에 관한 정보를 저장하지 않습니다. 저장하는 모든 것은 기기에 있으며 거기서 삭제합니다.

  1. Android 설정 → 앱 → Gleamvox → 저장공간 → 데이터 삭제를 엽니다. 학습한 단어, 설정, 클립보드 기록이 삭제됩니다.
  2. 또는 앱을 삭제하세요. 모든 데이터가 함께 삭제됩니다.

Android 자체 사용자 사전에 추가한 단어는 시스템 소유입니다. Android 설정(언어 → 개인 사전)에서 삭제하세요. 문의: support@gleamvox.com
