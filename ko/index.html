Gleamvox

똑똑한 추천을 갖춘 프라이빗 키보드

Gleamvox는 입력한 내용을 휴대폰에만 보관합니다. 오프라인으로 작동하며 텍스트를 어디에도 보내지 않습니다.

Google Play에 곧 출시

설계부터 프라이빗

인터넷 권한이 없습니다. 입력하거나 말하거나 복사한 내용은 휴대폰 밖으로 나갈 수 없습니다. 광고, 분석, 계정이 없습니다.

똑똑한 추천

여러 언어의 내장 사전으로 교정과 다음 단어 추천을 모두 기기에서 제공합니다. 내 단어를 학습하지만 비밀번호 입력란에서는 학습하지 않습니다.

다양한 언어

키 하나로 언어를 전환합니다. 언어별 여러 자판 배열, 이모지, 기호, 숫자 줄을 제공합니다.

클립보드와 음성

한 번 탭으로 붙여넣는 클립보드 기록(사진 포함). 휴대폰 자체 음성 인식을 이용한 음성 입력.

Gleamvox는 GNU 일반 공중 사용 허가서 v3.0에 따른 자유 소프트웨어이며 HeliBoard를 기반으로 합니다. 소스 코드
