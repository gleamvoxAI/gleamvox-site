Meine Daten löschen

Gleamvox hat keine Server und keine Konten und speichert nichts über Sie außerhalb Ihres Telefons. Alles, was es speichert, liegt auf Ihrem Gerät, und dort löschen Sie es:

  1. Öffnen Sie Android-Einstellungen → Apps → Gleamvox → Speicher → Daten löschen. Das entfernt gelernte Wörter, Einstellungen und den Zwischenablageverlauf.
  2. Oder deinstallieren Sie die App: Alle ihre Daten werden mit entfernt.

Wörter, die Sie dem eigenen Benutzerwörterbuch von Android hinzugefügt haben, gehören dem System: Entfernen Sie sie in den Android-Einstellungen (Sprachen → Persönliches Wörterbuch). Fragen: support@gleamvox.com.
