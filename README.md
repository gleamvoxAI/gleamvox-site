# gleamvox-site

The static site of Gleamvox, https://gleamvox.com, published with GitHub Pages (file `CNAME`).
Generated by `tools/site/build_site.py` of the Gleamvox project: do not edit the HTML by hand.
13 languages (en at the root, the others at /ru/, /es/ ...), no trackers, no cookies, no external requests.
The only script (`assets/lang.js`) remembers the chosen language in the browser and, on the first visit to the English
home page, opens the language of the browser if the site has it.
