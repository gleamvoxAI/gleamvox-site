# gleamvox-site

The static site of Gleamvox, https://gleamvox.com, published with GitHub Pages (file `CNAME`).
Generated by `tools/site/build_site.py` of the Gleamvox project: do not edit the HTML by hand.
13 languages (en at the root, the others at /ru/, /es/ ...), no trackers, no cookies.
`assets/lang.js` remembers the chosen language in the browser and, on the first visit to the English home page, opens the
language of the browser if the site has it, and shows "Account" instead of "Sign in" in the header while the tab has a live
sign-in. The account page (`/account/`, `assets/account.js`) talks only to https://api.gleamvox.com; the sign-in is kept
only in the session storage of the open tab, at most 1 hour (never local storage, never cookies). The payment page (`/pay/`,
`assets/pay.js`) loads Paddle.js from https://cdn.paddle.com only when a payment is opened (no secrets on the site).
